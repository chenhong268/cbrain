# Known Issues

## v0.3.0

### FTS 短词 LIKE 排名平权

- **现象**：2-char 短词（如"诺华"）走 LIKE fallback，所有结果同分，排名按插入顺序而非相关性。
- **影响**：短中文词搜索结果排序不够精准。
- **方向**：加 TF（词频）排序或 BM25 简化版。

### NER 提取质量依赖 LLM

- **现象**：NER 实体提取依赖 GLM-4-flash，极端情况下可能遗漏或误提取。
- **影响**：自动提取的 stub 可能需要人工检查补充。
- **缓解**：`cbrain health` 可以检查内容薄弱的 stub，`cleanup` 协议可以批量清理。

### 大量页面时 sync 较慢

- **现象**：141 页全量 sync 约需 30-60 秒（含向量化和 NER）。
- **影响**：大知识库的首次 sync 可能需要等待。
- **缓解**：增量 sync 只处理变更文件，日常使用不受影响。LanceDB 可以删除重建（README 中说明）。
