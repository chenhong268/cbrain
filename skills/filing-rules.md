# Filing Rules — pageType 判断决策树

> 新内容进来，应该用什么 pageType 存入 CBrain。

## 决策树

```
新内容进来 → 判断 pageType
│
├─ 是一个具体的人、公司、产品、组织？
│   特征：有明确名称、可以建立关系网络、会多次被引用
│   → entity
│   示例：星辰科技（公司）、张三（人）、Claude（产品）
│
├─ 是公认的方法论、理论、模型、定律？
│   特征：有名称的知识框架、跨领域可引用、不是日常用语
│   → concept
│   示例：奥卡姆剃刀 ✅、注意力管理 ❌（太通用）、RAG ✅
│   禁止：通用商业术语、日常品质形容词、管理常识
│
├─ 是事件记录、文章笔记、会议纪要？
│   特征：时间性强、事实性内容、不需要反复引用
│   → record
│   示例：会议纪要、文章摘要、项目进展记录
│
└─ 是系统生成的分析、发现、洞察？
    特征：由 brain_storm / discovery 系统产出、跨实体关联
    → insight
    示例：结构洞发现、模式识别、跨域关联
```

## 灰区决策

| 场景 | 默认 | 原因 |
|------|------|------|
| 不确定 entity 还是 concept | entity | 宁可建实体，发现是概念再改 |
| 知识性文章（如论文笔记） | record | 不是实体也不是概念，是学习记录 |
| 一个新术语（如 "Resolver 模式"） | concept | 如果有明确定义且跨域可用 |
| 一条简短观察 | record | 信息量不足以建独立页面 |

## 禁止

```
❌ 通用商业术语当 concept：注意力管理、品牌策略、团队建设、客户导向
❌ 日常品质形容词当 concept：创新精神、领导力、执行力
❌ 管理常识当 concept：绩效考核、目标管理、时间管理
```

## 目录映射

- entity → `brain/nodes/`（entities 和 concepts 已合并）
- concept → `brain/nodes/`
- record → `brain/records/`
- insight → `brain/insights/`
